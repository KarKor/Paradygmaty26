%zad3%

% Warunek końcowy: gdy X = Y, wynikiem jest X.
nww(X, X, X).

% Przypadek, gdy X > Y. Odejmujemy Y od X.
nww(X, Y, Res) :-
    X > Y,
    X1 is X - Y,
    nww(X1, Y, Res).

% Przypadek, gdy X < Y. Odejmujemy X od Y.
nww(X, Y, Res) :-
    X < Y,
    Y1 is Y - X,
    nww(X, Y1, Res).

% Zdefiniowane relacje
% Produkt można wyprodukować, jeśli dla danego produktu X nie brakuje żadnego składnika.
moznaprodukowac(X) :-
    produkt(X),
    \+ (potrzebuje(X, Y), \+ dostepny(Y)).

%zad5%

?- append([olej], [woda], [olej, woda]).
    Zwróci: true. (lub yes) - Prolog potwierdza, że połączone listy dają wskazaną trzecią listę.

    ?- append([olej], [woda], Co).
    Zwróci: Co = [olej, woda]. - Prolog łączy dwie listy i wpisuje wynik do zmiennej Co.

    ?- append([olej], Co, [olej, woda]).
    Zwróci: Co = [woda]. - Prolog odgaduje, jakiej listy brakuje, aby równanie było prawdziwe.

Zastosowania append/3:

    Łączenie list: Tworzenie jednej, złączonej listy z dwóch mniejszych.

    Dzielenie list (dekompozycja): Szukanie brakującej części (jak w przykładzie 3), lub zwracanie wszystkich możliwych podziałów listy na dwie mniejsze.

    Sprawdzanie: Weryfikacja, czy dana lista jest wynikiem sklejenia dwóch innych określonych list.

%zad7%

% Element znajduje się w liście, jeśli jest jej głową.
należy(X, [X|_]).

% Jeśli nie jest głową, sprawdzamy rekurencyjnie ogon.
należy(X, [_|Ogon]) :- 
    należy(X, Ogon).

%zad8%

% Pusta lista ma długość 0.
długość([], 0).

% Długość listy to długość jej ogona powiększona o 1.
długość([_|Ogon], Dł) :-
    długość(Ogon, DłOgona),
    Dł is DłOgona + 1.


%zad 9%

% Suma elementów pustej listy wynosi 0.
suma([], 0).

% Suma to wartość głowy + suma reszty (ogona).
suma([Głowa|Ogon], S) :-
    suma(Ogon, SOgona),
    S is Głowa + SOgona.

%zad 10%

% Element jest ostatni, jeśli jest jedynym elementem w liście (ogon jest pusty).
ostatni(X, [X]).

% W przeciwnym razie odrzucamy głowę i szukamy na końcu ogona.
ostatni(X, [_|Ogon]) :- 
    ostatni(X, Ogon).


%zad 11%

% Odwrotność pustej listy to pusta lista.
odwróć([], []).

% Aby odwrócić listę, odwracamy jej ogon i doklejamy głowę na sam koniec.
odwróć([Głowa|Ogon], Odwrocona) :-
    odwróć(Ogon, OdwroconaOgon),
    append(OdwroconaOgon, [Głowa], Odwrocona).
